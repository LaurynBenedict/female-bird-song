FEMALE BIRD SONG STATIC WEBSITE

This folder is a serverless static reconstruction generated from the WordPress WXR export and recovered media.

DEPLOYMENT
Upload the CONTENTS of this folder to the root of any static web host. index.html must remain at the root.

No PHP, WordPress, database, or build step is required.
